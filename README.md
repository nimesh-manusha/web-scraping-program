Web Scraper for Books
This project is a Python web scraper designed to extract structured data (book title, price, and stock availability) from an online bookstore (Books to Scrape) and save the data into a CSV file.

Features
Scrapes book title, price, and stock availability.
Extracts data from multiple pages (1-50).
Saves extracted data in a books.csv file.

Technologies Used
Python
BeautifulSoup
Requests
CSV
